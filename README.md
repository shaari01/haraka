# نَبض (haraka) — برنامج الصور المتحركة

برنامج شخصي لـ أ. علي الشاعري لتحريك التصميمات والصور الفنية والتراكيب الخطية، وتصديرها MP4 وGIF وWebP.
تطبيق ويب قابل للتثبيت (PWA)، يعمل بلا إنترنت، وواجهته عربية.

**الرابط:** https://shaari01.github.io/haraka/

## الفكرة
العنصر يُخزَّن **مرة واحدة** في المكتبة، وعلى المشهد **نسخ مرتبطة** منه، وتضع **مفاتيح** (هنا الموضع كذا، وبعد ثانيتين كذا) والبرنامج يحسب ما بينهما. حركة ناعمة من طبقة واحدة ومفتاحين بدل مئة طبقة.

## للمطوّر
```bash
npm install
npm run dev        # تشغيل محلي
npm test           # اختبارات الوحدات
npm run e2e        # اختبارات المتصفح (Playwright: لابتوب + جوال)
npm run build      # بناء النسخة المنشورة في dist/
```

- `PROGRESS.md`: ما أُنجز في كل مرحلة.
- `DECISIONS.md`: القرارات وأسبابها.
- المواصفات الأصلية: ملف «03-برنامج-الصور-المتحركة.md» في مشروع Claude.
